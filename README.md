# بک‌اند پلتفرم برنامه‌ریزی مطالعاتی کنکور

فاز ۰: پی‌ریزی پروژه + مدل دیتابیس + اتصال.

## پیش‌نیازها

- Node.js نسخه ۱۸ به بالا
- PostgreSQL نصب‌شده (لوکال یا یک سرویس ابری مثل Railway/Neon)

## مراحل راه‌اندازی

1. نصب پکیج‌ها:
   ```bash
   npm install
   ```

2. کپی فایل تنظیمات و پر کردن مقادیر واقعی:
   ```bash
   cp .env.example .env
   ```
   سپس مقدار `DATABASE_URL` را با اطلاعات دیتابیس واقعی خودت جایگزین کن.

3. ساخت جدول‌ها در دیتابیس بر اساس مدل تعریف‌شده:
   ```bash
   npx prisma migrate dev --name init
   ```
   این دستور هم جدول‌ها را می‌سازد و هم Prisma Client را تولید می‌کند.

4. ساخت تگ‌های پیش‌فرض (پیشروی، تمرین، مرور، آمادگی امتحان):
   ```bash
   node prisma/seed.js
   ```

5. اجرای سرور در حالت توسعه (با ری‌استارت خودکار روی تغییر فایل):
   ```bash
   npm run dev
   ```

6. تست سلامت سرور:
   مرورگر یا Postman را باز کن و به آدرس زیر برو:
   ```
   http://localhost:4000/health
   ```
   اگر پاسخ `{"status":"ok",...}` را دیدی، فاز ۰ با موفقیت انجام شده.

## ساختار پوشه‌ها

```
prisma/
  schema.prisma     مدل دیتابیس
  seed.js            اسکریپت ساخت تگ‌های پیش‌فرض
src/
  app.js             تعریف اپ Express و middleware ها
  server.js           فایل اجرایی که سرور را بالا می‌آورد
  config/prisma.js    اتصال singleton به دیتابیس
  routes/            (فاز بعد) مسیرهای API
  controllers/       (فاز بعد) منطق هر route
  middleware/        (فاز بعد) مثل auth middleware
```

## مرحله‌ی بعدی (فاز ۱)

بعد از اینکه این فاز را اجرا کردی و `/health` جواب داد، مرحله‌ی بعدی ساخت
سیستم ثبت‌نام/ورود (auth) است: مدل User همین الان در schema آماده است،
فقط باید route های `/api/auth/register` و `/api/auth/login` نوشته شوند.
